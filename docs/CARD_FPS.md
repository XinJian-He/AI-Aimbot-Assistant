# 采集卡格式帧率修复

- 明确选择分辨率/帧率/像素格式后，失败直接报错，不再回退到 1080p 或其他自动模式。
- MF 和 DirectShow 打开后核对实际分辨率和帧率。帧率仅允许 0.005 FPS 的格式序列化误差；59.940 与 60.000 不能互相冒充。
- CardCapture 在取帧前按所选帧率等待，只消费最新样本；回调更快时合并中间帧，不排队、不追赶补帧。自动模式采用设备报告的有效帧率。转换、推理耗时以及更低的全局帧率上限仍会降低实际帧率。
- MF 样本编号随样本在同一锁内发布，避免取帧后读到另一帧的全局计数；CardCapture 拒绝重复消费相同编号。
- 预览去掉固定 8ms/125FPS 丢帧判断，每个完成的推理帧最多显示一次，未显示的旧帧被最新帧替换。

这不按画面内容去重：静止场景中的相同像素属于合法新帧；采集卡对 60Hz 输入补成 180FPS 的画面也无法凭回调编号识别。输入信号刷新率需与采集格式相匹配。

验证时手动重编译并重启，分别选 60、180 格式，应用后重新开始，检查日志是否拒绝格式不匹配。观察实际采集与推理帧率：不得超过所选格式；性能不足时可低于该值。未运行 C++ 构建或实际采集卡测试。
