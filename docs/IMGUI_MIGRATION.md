# 原生 ImGui 界面

工程：E:\AIaim\aim-QQLive-DML1。界面基于 E:\AIaim\imgui_ui 的设计，原设计目录未改动。

## 接入

- 原有 aimlib DLL、采集、检测、控制、设备实现保持原架构。新增 src/ui，以 Aim C API 接入参数和操作。
- UI 在独立线程中运行 Win32 + D3D11 + DirectComposition；PNG 编译为 DLL 资源。窗口缩放、主题、滑块动画、开关动画和导航动画沿用设计，连接状态增加轻微呼吸效果。
- Aim_ShowUI 在窗口就绪后返回；Aim_CloseUI 等待当前 UI 操作结束；Aim_IsUIOpen 查询生命周期。Aim_Shutdown 先关闭 UI，再关闭后端。不得在 DllMain / loader lock 中调用关闭或等待接口。
- 关闭窗口本身不改变宿主拥有的处理生命周期；host_test 在窗口关闭后调用 Aim_Shutdown。
- 界面参数先编辑为草稿，点击“应用参数”后逐项回读并保存到 DLL 旁的 配置/aim_config.ini。失败会显示具体字段，不会把所有草稿标为成功；校验通过后的并发后端拒绝仍可能产生部分应用，以回读为准。
- 连接、模型启动、应用及 INI 保存/加载采用串行异步操作；设备/格式枚举与后台状态快照分别异步读取，避免渲染线程等待配置锁。变更操作期间参数控件禁用，日志页仍可查看；操作超时不自动重试。采集修复与实机验证步骤见 [CAPTURE_UI_FIX.md](CAPTURE_UI_FIX.md)。
- 移动测试需要当前设备连接代次匹配且处理暂停；发送成功表示指令已提交，不是硬件执行确认。
- 热键直接存储 VK，1/2/4/5/6 为鼠标键，其余支持键盘 VK。KMBox 鼠标监听和 MAKCU 固定 negotiated 4M 策略保持原后端实现。
- 六种采集方式均保留，采集卡支持实际枚举；实时图像继续使用原有外部预览窗口。侧栏与图表使用后端遥测，移除了演示资源占用数字。
- 配置档案保存为 INI；另存为支持选定路径，档案列表扫描 DLL 旁 配置 目录；其他位置可通过“导入 INI”打开。JSON 快照只修改草稿，应用前进行格式和值校验。旧 image_source/camera_index、MAKCU scheme 和 GBK 配置兼容仍保留。
- 模型类别通过已有元数据接口读取；模型列表扫描 models 和 model 目录。inference_engine/onnx_device 是现有后端兼容项，只读展示，未增加新的推理引擎切换实现。
- 原 Web 服务、HTML、内嵌页面头、页面打包器及 Web 专用测试从活动工程移除；原件保留在 backups/imgui-migration-20260930。

## 手动编译

打开 aimlib.sln，选择 x64，先“清理解决方案”，再“重新生成解决方案”。原构建中的非 UI 内嵌模块打包步骤仍保留。

工程已添加 ImGui 核心、Win32/D3D11 后端、资源文件及必要系统库，无需另外安装 UI 依赖。

随项目附带的 opencv_world.lib 使用 Release CRT 和 STL ABI，因此 aimlib 的 Debug 改用 /MD、_ITERATOR_DEBUG_LEVEL=0，并保留调试信息；不再使用 /MDd。修改配置后必须重新生成，避免旧 .obj 继续触发 LNK2038。

构建后可运行 x64/Release/host_test.exe --ui，或使用原宿主启动入口。现有二进制尚未更新，只有重新构建后才会显示新界面。
