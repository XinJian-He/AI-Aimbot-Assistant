# MAKCU 固定连接策略与移动测试

当前生产工程只接入 **Compatible SDK / negotiated 4M**（编号 2）：

- SDK：makcu-cpp@9874efa96f58e7a768e0110d765f0fa072e7e25e。
- 协议：ASCII。
- 连接：connect(port, true)，从 115200 协商至 4000000。
- 指定 COM 端口失败不换端口；仅显式填写 AUTO 时扫描。
- 旧配置中的方案 1/3/4 在加载时统一迁移到 2；API 不再允许切换其他方案。
- 原波特率配置键为兼容旧配置保留，不控制 SDK 的连接策略；原生界面不提供波特率输入。

方案 1/3/4 不再注册，方案 3/4 适配器和 mak-suite SDK 已移出生产工程。旧源码和旧传输测试仅作为历史参考，不参与应用的连接路径。

## 使用

在执行设备中选择 MAKCU，填写串口后点击连接。保持处理链路暂停，在移动测试中点击四方向按钮，或输入 X/Y 后执行一次。无需加载模型，也无需选择方案或确认默认。

每轴支持 -32768～32767 的整数，不能同时为零。发送成功只表示调用提交，请观察实际设备移动；超时不会自动重发或反向复位。

## 输入

KMBox 的五个鼠标键只读取 kmNet_monitor_mouse_*。断连、监听未开启或监听过期时按松开处理，不回退到系统状态或 Raw Input；键盘热键保留原读取方式。

MAKCU 保留本机 Raw Input 输入方式，关闭 SDK 按钮流。输出暂停、连接代次校验及并发保护保持有效。
