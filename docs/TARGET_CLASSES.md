# 类别顺序与模型类别名称

- 类别 ID 从左到右优先，例如 0,5：优先选择范围内、置信度合格且已确认的 0 类轨迹。高优先级类别可以打断低优先级锁定。
- 同类别保留原目标 ID；初次选择或丢失超限后选择离画面中心最近的候选。沿用已有的短暂预测和丢失宽限。
- 留空不选择目标，移除当前锁定类别后立即解除该锁定。跟踪关联禁止跨类别继承 ID。
- 模型成功加载后，通过 ONNX Runtime 元数据读取 names / classes，支持 Python 字典及 JSON 字典、列表。优先由输出形状推导类别数量，必要时读取 nc / num_classes。
- 原生界面通过“刷新模型类别”和“查看类别”读取当前模型元数据；不提供虚构的默认类别名称。
- 切换模型、加载失败及服务断开时不把旧模型名称显示成新模型名称。类别信息在加载时生成，通过线程安全快照随状态同步。

验证：纯 C++ 行为测试保留在 tests/target_classes_test.cpp；原生界面接入尚需手动编译和交互验证。
